# 写作阶段详案：逐板块结构、句式与坑点

> 本文件是 SKILL.md 阶段二的展开。按论文板块顺序组织，每节含：结构模板 → 句式/短语 → 常见坑 → 检查清单。

---

## 1. 题目（Title）

**作用**："题好一半文"。投稿阶段主编看题目+摘要决定送审与否；审稿阶段审稿人只看题目摘要决定是否接受审稿邀请——题目无趣会直接拖慢审稿进度。

**构成要素**：研究对象、研究内容、研究方法、研究数据、研究区域的排列组合（不必全含），可加创新点提示（perspective from / approach）。

**高效套路**：
- `-ing` 开头 + 冒号递进组合，效果好且信息全面；
- 冒号二级递进会让题目变长但非常具体，能展示亮点（注意字数限制：如 Part D ≤12 词，部分期刊 ≤15 词）；
- 结论式题目：把核心结论/反直觉发现直接写进题目，适合冲击好期刊；
- 问句形式：可回答可不回答（如 "Does TOD need the T?"），前提是工作足够新颖。

**禁用清单**：
- 禁用 very unique / new / novel / innovative 自我标榜——招人恨，是否创新由主编审稿人判断；
- 禁用 "study on / research on"（"……的研究"是中式英语）；
- 避免与现有论文重名或相近。

**日常积累**：收集好题目如收集好标题；可用 AI 生成备选，但必须自己架构提示词、自己把关。

## 2. 摘要（Abstract）

**地位**：决定论文生死的第一关。主编凭题目+摘要判断论文价值并决定是否送审。换刊改投时通常要重构题目和摘要。

**五段式结构**（论文是"八股文"，摘要高度结构化）：

| 板块 | 内容 | 篇幅 |
|---|---|---|
| ① 背景/动机 | 三句话：a) 研究对象为什么重要（它往往是一个很重要的手段）；b) 过去大多怎么做、存在什么缺陷（gap）；c) 这样的缺陷带来什么不良后果 | 3 句 |
| ② 方法 | 承接语 "To address this gap, this study develops/investigates ... using the data from ..."，概括数据、方法、过程（对应引言任务段） | 1–2 句 |
| ③ 结果 | "Results show that ..."，**量化结果**，通常 2–3 点，可用冒号 + (1)(2)(3) 列出 | 2–3 句 |
| ④ 结论 | "These findings suggest that ..."，结论 ≠ 结果：结果是具体数值关系，结论是方向性/机理性判断（如正向影响、非线性、存在阈值区间） | 1–2 句 |
| ⑤ 意义/贡献 | 浓缩 intro 贡献段与结论贡献段为一句：状语 + 主谓宾，如 "By integrating ..., this study advances the understanding of ..., promoting ..." 或只挑最重要的一点写得宏观些 | 1 句 |

**关键规则**：
- 结果若只有一点，说明工作量可能不够或 gap 不够——回头补强；
- **贡献必须具体，拒绝假大空**：判定标准——这句话换到同题材任何论文都能用，就是假大空。要写清转变了什么工作范式、促进了什么理解、带来什么分析方式；
- 详略可调：做方法的论文方法部分多写，做实证发现的方法部分简写；不同学科侧重点不同，灵活调整；
- 注意期刊字数硬限制（如 Part D ≤150 词），字字珠玑。

## 3. 引言（Introduction）

**地位**：全文看似最不重要、实际最重要的部分；看似最简单、实际最难写。所有研究的必要性、迫切性都在 intro 体现。审稿人说 "the introduction is successful" 是极高评价。

**四段论**（任何题材、领域通用）：

### 第一段：研究背景段
- 不是区域背景，而是科学问题核心的描述；
- **最后一句必须点出"干什么事情很重要/很迫切"**——干的那件事就是题目主题；
- 前面每句为最后一句铺垫，句句咬合、环环相扣、层层递进；
- 示例结构：宏观形势 → 两条路径（供给侧已进展、需求侧是潜力手段）→ 用此手段必须知道机理 → 因此探究该机理极其迫切。

### 第二段：Gap 段（动机段）
- **每个 gap 的首句必须是否定句式、一针见血**，先直给 gap 再说过去：用 "remains unclear / remains limited / remains unexplored / has not been ..."，不要先罗列 "previous studies did ..."；
- 过去怎么做不代表 gap——过去有当时的条件形势；
- 有几个 gap 写几点（first / second），穿插证据与参考文献；
- 写 gap 的两种方式：a) 已有研究但做得少/有缺陷；b) 实证类直接从现象入手——"某某现象 remains unclear / remains unexplored"；
- **只有一个 gap 时**：不能只用 first 一点，要把大 gap 瓦解成若干小点，避免显得单薄；
- 每点 gap 末尾可点明"因此，解决 X 对 Y 是急需的"。

### 第三段：任务段
- 固定短语承上启下："To address these gaps, this study ... using ... data"；
- 然后 "first ... second ... third ..." 交代具体做了什么（数据、方法、设计）。

### 第四段：贡献段
- 站位要高：不写"我做了什么"，写"带来了什么好处、转变了什么范式、促进了什么理解"；
- 常用动词：shift（转变工作范式）、advance（促进理解）、extend、promote、clarify、translate；
- 结构："This study advances/shifts ... First ... Second ... Third ..."，可加 "by integrating ..." 状语；
- **禁用夸大词**："创新性的""首次""填补空白"——是否如此由审稿人/主编/读者判断；若确属首次，谦虚表达 "To the best of our knowledge, ..."。

### 第五段（可选）：章节安排
- "The rest of this paper is organized as follows." —— 现在大部分期刊不鼓励写（占用版面、千篇一律），一般不写。

## 4. 文献综述（Literature Review）

**作用一句话**：总结前人在本研究上所做的工作，明辨其中不足，为本研究提供理论依据。

**结构规则**：
- 与引言 gap 一一对应：几个 gap 几个 subsection（2.1 / 2.2 / 2.3）；
- 最后加一个 "research gaps" 总结小节：纯结论式重述 gap（"First, ... remains ...; Second, ... remains insufficiently understood"），不插参考文献（前文已引），并点明"这样的 gap 需要我们去做一/二/三这三项工作"；
- 总结小节给审稿人看——审稿人可能扫读，需替其归纳；
- **不要在总结小节写 "this study 将怎么做"**——具体做法属于 method 章节，这里只写"需要什么"。

**子节内部组织（以因果 gap 为例）**：
1. 该关联已存在大量研究（跨区域、多产出维度）；
2. 分维度摆证据（不同框架下的发现，结论可能不一致）；
3. 转折：相关 ≠ 因果，引出机制性障碍（如居民自选择的内涵）；
4. 过去如何应对该障碍（方法谱系）→ 话锋一转：只能接近不能根除 → 最理想的自然实验不可实现；
5. 小结：因果链未建立，急需新方式——点出本研究的动作。

**严禁流水账**：禁止"张三采用什么方法、得到什么结论；李四……"。正确做法——归纳成维度（如刀具、片数、切法并列），每个维度一句话带一串参考文献，再逐维度展开证据与矛盾，最后总结 gap。审稿人只看你讲得有没有道理：摆事实、讲证据、有道理就 OK。

**两种写法**：
- 荟萃分析（meta analysis）：几百篇论文统一归类，列自变量/因变量/样本量/弹性系数，量大取胜，较少见；
- 阐述评论（主流）：靠逻辑层层递进，有明确线索贯穿（如：关联 → 相关≠因果 → 因果如何做 → 仍无法剔除 → 因果链断裂）。

**贡献定位决定综述侧重**：做新方法 → 综述按方法分类、比较优缺点、指出缺陷引出自己的改进；做实证 → 综述各维度证据的不一致之处。

**其他要点**：
- 讲最新进展（行业手册最新版、近年代表作）；
- 追本溯源，勿以讹传（二次引用必须回看原文）；
- 切记不可原文照抄（查重 + 抄袭风险）——在自己理解基础上、大量文献交织下重写，个人语言体系如指纹，自然不重复；
- 写得好/被审稿人引用的论文值得单独展开；综述质量是录用的重要决定因素，审稿人可能就是被引作者。

## 5. 数据与方法（Data & Methods）

**数据部分（最好写）**：
- 交代数据来源与有效性：何时调查、什么问卷、收集多少样本、剔除不合法样本后剩多少、调查过程；
- 数据成体系时可单独成节（data source / collection / preparation）；现鼓励向配套期刊上传原始数据以获 credit。

**方法部分（核心：可重复性 reproducible）**：
- 英文论文与中文论文语境相反：中文微言大义，英文必须具体——别人要能按你的描述、用相同数据重复出实验，这是科学金标准，审稿有一项 reproducible；
- 新方法：给足信息（结构、变量、参数估计）；
- 经典方法（如 robust 回归、Lasso）：不必交代太多细节，列出方程结构、变量、参数估计方式即可；
- **清晰明了 ≠ 简单**；故意搞得神秘复杂也不高端。

## 6. 结果与讨论（Results & Discussion）

**讨论核心词：交互**。结果要与现有工作交织：
- 为什么有这样的结果？为什么是正向的、为什么是这个量级？找证据支撑；
- 与前人互证：你的结果支撑了谁、谁的结论验证了你；
- 与前人相反：发现截然不同结果时，说明前人可能未考虑什么，可以反驳；
- 延伸：带来什么新启示、拓展。

**结果 vs 结论**：结果（results show that）是具体数值/形态关系；结论（findings suggest that）是方向性判断。多数情况结果与讨论写在一起，避免重复。

**Policy Implications**：实证类论文一般单独成节（也可叫 practical guidance / takeaway for practice），也要引文献、做交互——你的启示是否稳健，前人是否得到过部分类似的初步结论可作支撑。

**图表**：
- 图要自成体系：注释完整，不看正文也能读懂大概；与数字、文字有机结合；一图胜千言；
- 配色美观会直接影响第一印象，甚至决定生死；
- 工具互补：Python / MATLAB（风格不同）、R、SPSS（统计表直接导出粘贴）、Excel（某些折线图效果好）、draw.io / Visio / PS / AI（后期修饰）；
- 表格用三线表（顶线、栏线、底线）。

---

## 7. 结论（Conclusion）

**三加一结构**（与引言呼应，回答引言提出的问题）：

1. **结论段**：用了什么方法、基于什么数据、做了什么分析、得到什么结果与结论、有什么启示——2 到 3 句即可，不要太长也不要太单薄；
2. **贡献段**：这里必须写（引言的贡献段只是给审稿人的预告）。单刀直入、不重复，站位要高但实打实——在做的工作基础上拔高，用 shift / advance / promote / leading to 等词；
3. **局限（Limitations）**：客观存在但**不致命**的不足（如样本量小、缺失值需估计）。致命的不会写——不写"搬起石头砸自己脚"的缺陷；一般都要有；
4. **未来展望（Future Study）**：
   - 建议与 limitation **分开写**：有些缺陷（如缺失值）未来也解决不了，二者不必然对应；
   - 展望必须建立在当下工作基础上：因人力/财力/篇幅未做、未来紧迫需要做的扩展；
   - **不能太跳跃**：不能从当前主题一下跳到不相干的大方向（如"未来做自动驾驶"），必须与本文直接相关。

**章节安排建议**：结论章内可分 6.1 Conclusion（或 Conclusion and Contributions）、6.2 Future Study。

## 8. 语言与逻辑（Language & Logic）

**逻辑是重中之重**：
- 恐惧来源于无知——知道逻辑就不会恐惧，如律师熟悉法律条文；
- 要求：字字句句咬合、层层递进；每一句与上下句衔接，不跳跃；
- 评审/诊断时以"律师定罪"标准逐句检查：这句的结论有没有前一句的证据支撑。

**直接写英文，严禁汉译英**：
- 中英文语境截然不同：中文微言大义，英文具体直接；
- 典型错例："研究切入点" ≠ "entry point of study"，英文对应概念是 "research gap"；"可达性分析"不能译成 "the analyze of accessibility"；
- 要么直接用英文写，要么把意思给 AI 生成初稿后自己调整，但不要整段汉译英。

**多用短句**：老外喜欢短句，长句只在法律文书等极书面场合；能短就短，短句讲清楚就是高水平。

**词汇替换意识**：避免重复用词，积累替换库——likely / apparently / dramatically / frankly / obviously 等。

**语感维护**：每天至少读一篇论文，保持信息输入；英文放一学期会生疏。写作能力的质变来自第一篇 SCI 手写完成——量变产生质变，AI 时代也要保留手写训练。

---

## 9. 排版（Formatting）

- 遵循期刊模板；极少期刊规定两倍行距、字号 ≥12、Times New Roman；
- 单双栏、行距、字号不影响阅读即可；
- **页码和行号必须有**（系统生成或自行添加）；
- 参考文献格式不限——用 EndNote 插入，可在不同格式、平台间切换。

## 附：写作阶段快速自检清单

- [ ] 题目：无 study on / research on / novel 自我标榜；要素组合合理；符合字数限制
- [ ] 摘要：五板块齐全；背景三句话；结果量化且 ≥2 点；结论 ≠ 结果；贡献具体不假大空
- [ ] 引言：四段论完整；第一段末句点出主题重要性；Gap 首句均为否定句式直给；任务段 first/second/third；贡献段站位高、无夸大词
- [ ] 综述：子节与 gap 一一对应；末尾有 research gaps 总结小节；无流水账；层层递进有线索；最新进展已覆盖
- [ ] 方法：可重复——他人能按描述复现
- [ ] 讨论：每处结果都有与前人的交互；有 Policy Implications
- [ ] 结论：四要素齐全；limitation 与 future study 分开；future study 不跳脱本文
- [ ] 语言：非汉译英；短句为主；句句衔接；无重复用词堆砌
- [ ] 参考文献：新旧交替；引言前两段不太老旧；含 2–3 篇目标期刊论文；追溯原文、无照抄
- [ ] 排版：有页码行号；图表注释完整；三线表
